v2 - 2026-11-04
Output format: json_schema_v1.json (unchanged)
Model: gemini-3.8-flash (Vertex AI), thinking level "low" (unchanged)

What: Rewrote the definition of "place". The model is now told not to stop at the name of the
town, village or area, and to add street or road names, landmarks the path passes or connects
(school, shop, church, bridge, station, junction), and start and end points, combined into one
short description from general to specific. Added a made-up example of the expected format.
All other variables and rules are unchanged.
Added "bicycle parking" to the examples of cycling infrastructure
Also corrected the model line in the header (Vertex AI instead of the Gemini API); this does not
affect what the model receives.

Why: In the v1 test run on 5 articles, relevance matched the human coding well, but "place" was
less detailed than the human coding. Example: the AI coded "Homborsund" where the human coder
wrote "Homborsund ved Eide skole", so the landmark that locates the path was dropped. Detailed
places matter for georeferencing the paths in OSM later.

Evidence: Author's review of the v1 output for the first 5 articles (2026-11-04).
Note: The example in the prompt is invented on purpose, not taken from the coded articles, so the
prompt does not contain the answer to any article in the test data.
